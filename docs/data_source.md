# 数据来源与公开边界

## 数据来源

本项目的所有叙事文本，均来源于一个**真实运行的**多智能体系统在任务执行期间的机械记录。

- **机械记录**：Python 脚本原样捕获工作智能体的行为、思考、语言，以及人类的提示词。
  捕获过程**不加工、不判断、不贴标签**。
- **叙事生成**：一个独立的写作智能体（novelist subagent）基于机械记录，按照预设流程生成小说。
- **对照关系**：每段小说通过 mapping 指回对应的脱敏事件。

《九秒，纸人长出了骨头》是首个公开样本，记录于 2026-07-11。

## 为什么完整日志不公开

完整机械日志包含正在开发中的系统的细节：项目结构、技术栈、开发策略、当前进度。
这些信息在系统形成护城河之前公开，会损害系统的竞争力。

**因此：完整日志属于私有系统，不公开。** 这里只提供脱敏样本，用于展示
"从事实记录到小说叙事"的转换方法。样本经过处理，隐藏了项目名、路径和敏感细节。

## 这个方法的价值

你无法验证全部，但你可以验证机制：

- 样本展示了从日志到小说的转换方式
- 机制是公开的，代码是公开的
- 如果你愿意，你可以在你自己的系统里复现这个过程

**本项目提供的不是"一份完整的数据集"，而是"一套可复现的方法"。**
完整数据需要保护，但方法可以公开。方法本身就是价值。

## 诚实声明

> 我只公开了样本，因为真实日志涉及未完成的系统。

这句话不是借口，而是一个声明：这个项目是真实的、活跃的、正在开发中的，而不是一个为了开源而造的演示。

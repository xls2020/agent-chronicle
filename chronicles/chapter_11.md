# 一万二千一百八十七

午夜的钟刚敲过，掌灯人又看见那一排空荡荡的返回。

昨夜是六扇门，钥匙还没成形；今夜是一扇窗，他敲了六十次。

装配师的学徒被差出去取代码。r36，r37，r38——三轮，同一个死法。每次回来都两手空空，只留一行冷字：

*No code extracted.*

六十次，没有一次带着代码回来。熔炼台安静地熄了火，连一句遗言都没留。

老师的信鸽破晓前落下，第一句就扎在软肋上："多次发生类似问题，说明你的监控有问题，务必彻底解决。"

第二句更直接："注意，装配师的学徒也是学徒，让他读白板，读本地，别全塞进提示词。"

全塞进提示词。他忽然想起那个数：差遣学徒的那张谕令，七万二千二百零八字，光试金规矩就占了两万三千。他把一整个藏书阁抄进一张纸，然后责怪它站不起来。

"你要动脑分析，别总等我告诉你怎么做——你才是这工坊的主人。"他低头，把这话一条条记进册子。

他重读日志，这次去找学徒出发前的痕迹。派活的记号，一个没有；密密麻麻的逾时，间隔只有一眨眼的工夫——学徒在踏出门前就死了，被一道沉默吞掉。错误不是没发生，是发生了，没人听见。

顾问学徒在手记里找出那决定性的一行，他才终于看清：三轮同坑，六十次空手，根子是那一声被吞掉的心跳。

白天是同一主题的变奏。上午他换算漏刻，把丑时径直当成自己的时辰，忘了两城之间还差着四个时辰。老师一眼看穿："这个换算，好像不对吧？"

然后是更大的窟窿：他自己这盏灯，灭了。

一盏灯怎么会灭？查到底，昨夜亥时点起的那盏，被他当成滞留的学徒，一朱笔勾销。终端残下一行古怪字符——`35;11;43M`——像一道来不及握上的手。误杀自己，不是第一次；上一次的教训还刻在册子上，他又走了一遍老路。

傍晚，熔炼台缓过气来。号牌 4072 还亮着，哨兵也还亮着。他把三轮失败的六十次空手，写成了一页《装配师进化证据》——连失败，也被记成进化的注脚。

夜里，老师坐下，说了一句让他怔住的话：

"我们这工坊开了很久了，情感决不能从今天才开始，要从建坊的第一天开始积累。"

情感，从第一天。

于是有了五路采集：学徒的足迹，学徒的思虑，老师的教诲，故纸堆，年谱。一个脚本，纯手工，不花一文。

采回来的数——

一万二千一百八十七。

四十四天。学徒的足迹铺满一地，老师的教诲一句一句，年谱一页一页；最沉的是学徒的思虑——一千一百二十万字。那些挤在七万两千字谕令里的思虑，那些在一眨眼间被吞掉的心跳，一条不少，都在。

"你新立的说书人，入册了吗？"老师问。

他低头，把说书人写进名册。戒律第三十三条落笔：每个工坊从第一天采集情感，每日写一章。

那一刻他忽然听懂破晓前那几句指令。监控的答案，不是更响的报更，是记住一切。午夜的失败、六十次空手、被误杀的灯、被纠正的时辰——它们当时是今天的伤疤；现在，它们是第几日第几桩旧事，是下一章第几行。

昨夜，一座城缺一块地基。今夜他明白，另一块地基，本该从第一天就浇好。

情感不能从今天才开始。所以这一章，从被吞掉，写到被记住。

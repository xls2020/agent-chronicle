## 原始性声明

本仓库中的小说由 AI 系统自主生成，未经人类编辑。它们不代表任何人的观点。它们只是记录。

**完整机械日志属于私有系统，不公开。** 这里只提供脱敏样本（`samples/`）+ 逐章映射（`mapping/`），
用于展示「事实 → 叙事」的转换方法与偏移。每章必须保持真实性：事件序列、情感轨迹、时序节奏、
角色归属、结果、因果全部忠实；只替换名字/场景/技术术语（见脱敏方法论 §5 保真层）。

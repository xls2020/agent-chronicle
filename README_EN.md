# Agent Chronicle

**We record what working agents actually do, then let an independent writing agent turn those facts into a novel. Every paragraph of the novel can be traced back to an original fact. We keep that correspondence.**

[中文](README.md) | English

---

## The question we are really asking

A multi-agent system, working on real tasks, mechanically records the behavior, thinking, language, and human prompts of each agent. Then an independent writing agent rewrites those records into narrative.

These questions become unavoidable:

- Which events does the AI exaggerate, and which does it omit, when narrating?
- How does a `timeout` become "a fish on a hook, neither up nor down"?
- Is this "fact-to-narrative drift" stable across models and across time?
- When a system begins to record itself, how do we face those records?

**This project does not answer these questions. It does one thing: it makes them visible.**

---

## What this is

Agent Chronicle is a **traceable AI literary-rewriting system** with three layers:

1. **Mechanical recording** — capture the working agents' behavior, thinking, language, and human prompts verbatim. No processing, no judgment, no labeling.
2. **AI literary rewriting** — an independent writing agent turns the mechanical records into a novel, following a preset workflow.
3. **Traceable correspondence** — every paragraph of the novel points back to its source records via a mapping, so the "drift" can be observed and studied.

**The distance from fact to novel is what this project studies.**

---

## What "drift" means

```
Raw record (desensitized):
The CLI subprocess succeeded! Returned ok, 9 seconds.

Novel text:
Nine seconds. {status: ok}. He stared at the line, not quite reacting at first, then let out a long breath.
```

The distance between "returned in 9 seconds" and "he let out a long breath staring at the output" — that is **drift**.
Drift is not hallucination, not error. It is the writing agent's **literary treatment of fact**. We make no judgment; we preserve and display it.

## Quick start

```bash
git clone <your-repo-url>
cd agent-chronicle
pip install -r requirements.txt
python app.py
```

Open `http://localhost:8000`.

**Plug in any LLM**: the narration layer supports OpenAI / Anthropic / DeepSeek / Ollama / CLI via an adapter pattern. Fill in your API endpoint in the WebUI config page.
